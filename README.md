My Portfolio
This is my personal portfolio website made using HTML and CSS.
Files
- index.html contains the website structure.
- style.css contains the design and responsive styling.
How to open
1. Download the project.
2. Keep index.html and style.css in the same folder.
3. Open index.html in a web browser.
Responsive testing
The website can be checked at mobile, tablet and desktop screen sizes.
- Mobile: up to 600px
- Tablet: 601px to 768px
- Desktop: above 768px
The page uses Flexbox for the header and hero section, and CSS Grid for the skills section. It also includes hover effects, smooth scrolling, a fixed Back to Top link, a skills table and a contact form with required fields.

The contact form shows the front-end form design and browser validation. It needs a backend or form service to send messages.
